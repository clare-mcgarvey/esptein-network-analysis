# esptein-network-analysis
The construction and analysis of Jeffrey Epstein's social network, as derived from the 'Epstein Files'. 

Mapping the Epstein Files: A Network Analysis

This project aims to provide an exploration into the network of actors named in the 'Epstein Files', a collection of documents, images, videos and emails related to the U.S. financier and convicted pedophile Jeffrey Epstein. We use network science, link prediction, and epidemic-style diffusion modelling to examine how influence and information moves through the network.  

Data source: [Epstein-doc-explorer](https://github.com/maxandrews/Epstein-doc-explorer) (Andrews, 2025; snapshot 31/08/26) — entities and relationships extracted via AI from documents released by the House Oversight Committee under the Epstein Files Transparency Act (November 2025).
